# Bicharoco

Loja de coisinhas impressas em 3D, em Portugal.

Site: <https://bicharoco.sevenfaithtech.com/>

- `site/` — o site (HTML/CSS/JS). Instruções em [site/LEIA-ME.md](site/LEIA-ME.md).
- `marca/` — proposta de identidade da marca.

Cada push para `main` continua a publicar a pasta `site/` no GitHub Pages e, quando altera a aplicação em `loja/`, publica automaticamente a loja Laravel na VPS.
